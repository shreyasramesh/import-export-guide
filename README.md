# How to Make Your Own Physical Product — A Practical Guide

A single-page, static website that presents a generic guide to making a physical product from zero.

## Contents

- **Part 1 — Key terms and landed cost:** MOQ, tooling, certification, payment terms, tariffs, a worked landed-cost example ($8 EXW → about $12.50 landed), and the rule that retail price should be 3–5× landed cost.
- **Part 2 — Find and vet a factory:** direct listings, sourcing agents, and trade shows, plus a vetting checklist.
- **Part 3 — Samples to mass production:** design files, timelines (production 30–45 days), the golden sample, and third-party inspection.
- **Part 4 — Negotiation:** seven rules for working with factories without damaging product quality.
- **Part 5 — Cash flow and protection:** export credit insurance terms, action against counterfeiters, and a second warehouse near the factory.
- **The playbook:** eight steps for starting a hardware product from zero.
- **Landed-cost calculator:** pre-filled with the guide's worked example; recomputes landed cost and the 3–5× pricing verdict as numbers change.
- **Glossary:** 23 searchable key terms.
- **Research agent:** a visitor supplies their own Google AI API key and a research topic. The key is kept only in the browser tab's session storage and is sent only to the Gemini API. The agent answers from the full guide text plus live web search, separates guide guidance from researched facts, cites sources, and ends with next steps.

## Running it

Open `index.html` in a browser, or serve the folder with any static file host — no build step and no server code are required. The research agent is the only feature that needs a network call, and it runs entirely from the visitor's browser using the visitor's own API key.
